ANCL

Aether Natural Coding Language — native executables, zero runtime

Self-hosting  •  Windows PE32+ & Linux ELF  •  CRT-free

⚡ Compiles to native code

The anclc compiler emits hand-encoded x86-64 machine code and writes a valid Windows PE32+ or Linux ELF executable directly — no assembler, no linker, no LLVM, no C runtime.

🔌 Direct Win32 FFI

One-line extern "dll" declarations bind any Windows API at compile time. COM vtable dispatch is supported via callp(fnptr, args...).

🔄 Self-hosting compiler

ANCL compiles itself — on both Windows and Linux. The self-hosted compiler (anclc2) is written entirely in ANCL and reproduces itself byte-for-byte.

📦 Single-binary deployment

Every ANCL program compiles to one .exe that imports only DLLs Windows already ships. No installer, no runtime, no admin. Drop it on a locked-down field box and it runs.

# This very server — written in ANCL, compiled to a bare-metal .exe

import "../../../core_lib/std.ancl";
import "../../../core_lib/win32_api.ancl";

@DATA
HTTP_PORT: i64 = 8080;
hdr_200:   str = "HTTP/1.1 200 OK\r\nContent-Length: ";

@CODE
func main() -> i32 {
    WSAStartup(514, g_wsa);
    srv = socket(2, 1, 6);
    bind(srv, g_saddr, 16);
    listen(srv, 16);
    while 1 {
        client = accept(srv, 0, 0);
        serve(client);   # <-- you are reading this line's output right now
    }
    return 0;
}

🏗 Runtime code generation

ANCL programs can write ANCL source and invoke the compiler at runtime — generating, compiling, and executing new native tools on the fly without leaving the language.

🧪 OPC DA in 46 KB

A full native OPC DA client with COM vtable dispatch, server enumeration, tag browsing, and live polling — in a single 46 KB executable. The same tool in C# is 64 MB.

📊 Industrial protocol support

Built-in sockets + raw FFI make it straightforward to implement Modbus/TCP, FINS, S7Comm, IEC-104, IEC-61850/MMS, DNP3, BACnet, EtherNet/IP, and OPC UA clients — all as tiny native binaries.

🧠 Pure-ANCL AI engine

A complete LLaMA/GGUF inference engine — tokenizer, transformer, sampler, and a hand-emitted Vulkan GPU backend — written entirely in ANCL with zero ML dependencies. It runs real models on CPU and GPU, and fetches them over a pure-ANCL TLS 1.3 stack.

🔧 Rebuild it yourself

The compiler ships as its own ANCL source. Feed it to anclc and it recompiles itself into a byte-for-byte identical binary — verifiable self-hosting, no external toolchain required.

You are served by a native ANCL executable — no Node, no Python, no .NET, no libc.
