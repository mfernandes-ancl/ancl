ANCL SHEET

ANCL Sheet User Guide

A compact native data grid for CSV work, spreadsheet formulas, and safe SQLite browsing and editing. No runtime, no installer, and no bundled database library on supported Windows systems.

01Quick start

1
Open data. Press Ctrl+O and choose a .csv, .xlsx, .db, or .sqlite file.
2
Inspect a cell. Click it, or enter its row and column near the bottom and press Read.
3
Edit CSV data. Double-click a cell, or change Cell Value and press Apply.
4
Save safely. CSV Save writes CSV. SQLite Save creates a .bak and commits staged table changes in one transaction.
Portable: keep guide.html beside ancl_sheet.exe. Press F1 at any time to reopen this guide.

02The interface

Menus and path

File controls loading and saving. Edit contains clipboard and navigation commands. Data contains filters, row/column operations, and sorting. Help opens this guide, shortcuts, and About.

Grid and editor

The central grid displays up to 40 rows and 12 columns. The unified bottom panel contains the target row, column, value editor, current status, and capability summary.

The File menu keeps the three most recently opened files. History is stored in ancl_sheet_recent.txt beside the executable.

03CSV editing

  • Create a blank workbook with File > New.
  • Double-click a cell for in-grid editing.
  • Use Insert/Delete Row or Column from the Data menu.
  • Undo and redo are single-step snapshots.
  • Save writes standard quoted CSV and preserves commas inside cells.
Formula note: CSV Save writes calculated values for compatibility. It does not preserve ANCL Sheet formula source when the file is reopened.

04Read-only XLSX workbooks

Open a standard .xlsx workbook exactly like any other file. ANCL Sheet imports the first conventional worksheet, xl/worksheets/sheet1.xml, into the existing 40 by 12 grid.

  • Shared strings and inline strings are decoded.
  • XML entities such as &amp;, &lt;, and quoted text are restored.
  • Numbers, booleans, and cached formula results are displayed.
  • Find, filter, sort, copy, and CSV export remain available.
  • Apply, paste, formulas, row/column changes, and Save back to XLSX are blocked.
ANCL Sheet streams worksheet XML through Windows tar.exe; it does not extract a workbook folder or ship a ZIP library. Windows 10 version 1803 or newer is recommended for this feature.
Styles, Excel date formatting, macros, images, charts, encrypted workbooks, and non-conventional first-sheet layouts are not interpreted. Their underlying scalar values may still be visible where applicable.

05Formulas

Begin a CSV cell value with =. The grid shows the result; selecting the cell returns the original formula to the Cell Value field.

CapabilityExamples
Arithmetic=A2+B2*2, =(D2-1)/4
RangesA2:C8
FunctionsSUM, AVERAGE, MIN, MAX, COUNT
Errors#DIV/0!, #REF!, #CYCLE!, #ERROR!

References cover A1 through L40. Formula text is limited to 95 characters. Structural edits do not rewrite references in this version.

06SQLite browsing

Opening a database first shows its schema. The table dropdown lists user tables; SQLite-owned tables such as sqlite_sequence remain visible in Schema but are excluded from the picker.

  • Schema displays type, name, table, root page, and SQL.
  • View opens the chosen table.
  • Previous/Next move through 39-record pages.
  • Text, signed integers, REAL, NULL, BLOB markers, and rowid-backed integer primary keys are decoded.
  • Browsing uses ANCL Sheet's native SQLite page reader and needs no SQLite DLL.

07Transactional database editing

Table values can be changed by double-clicking a value or using Cell Value + Apply. Changes are staged in memory until Save.

1
ANCL Sheet copies the source database to <database>.bak.
2
It opens the database through the active SQLite writer and starts BEGIN IMMEDIATE.
3
Every staged value is updated by its SQLite rowid.
4
All updates succeed and COMMIT, or any failure causes ROLLBACK.

Save As: choose .db or .sqlite to copy the complete database and apply edits to the copy. Choose .csv to export the filtered page.

Unsaved database edits block page, table, and file changes. A sorted database page must be reloaded before editing so displayed rows cannot be matched to the wrong rowid.

08Copy and paste

  • Ctrl+C copies the selected cell or selected grid rows.
  • Use Ctrl/Shift selection to copy multiple visible rows as tab-separated text.
  • Ctrl+V pastes tabular or multiline data from the selected cell in CSV mode.
  • A comma in a single clipboard value remains in one cell.
  • Formula cells copy their formula source.

11SQLite writer providers

Database browsing is always handled by ANCL Sheet. Database writing selects the first available provider:

  1. Windows WinSQLite: winsqlite3.dll, included with Windows 10 version 1511 and newer.
  2. Fallback: a compatible sqlite3.dll placed beside ancl_sheet.exe.
  3. Neither: CSV and database browsing continue, but SQLite writing is unavailable.

Open Help > About to see the active provider. Windows 10 or newer is recommended.

12Current limits

  • Grid: 40 rows by 12 columns.
  • SQLite: up to 16 user tables and 12 displayed columns.
  • SQLite editing changes existing scalar values only.
  • Inserts, deletes, schema changes, explicit NULL assignment, BLOB editing, and WITHOUT ROWID writes are not supported.
  • SQLite overflow payloads are reported rather than decoded.
  • Spreadsheet formulas are a lightweight ANCL Sheet feature, not a full Excel calculation engine.
