01Quick start

1
Open or create a file. Use Ctrl+O, Ctrl+N, or File > New From Starter.
2
Edit with context. Line numbers, syntax colors, language mode, caret position, and save state stay visible.
3
Build ANCL. Save an .ancl file, then press Ctrl+B or F5.
4
Read the result. Compiler and program output appears in the captured output pane.
Keep guide.html beside ancl_pad.exe. Press F1 to open this guide.

02The interface

Header and menus

The title band identifies the workspace. File, Edit, Build, View, and Help use compact native menu buttons matching ANCL Sheet.

Editor and status

The framed editor combines a line-number gutter with a RichEdit code surface. The bottom panel reports line, column, language, encoding, line endings, and Modified/Saved state.

Find/Replace, Go To Line, and the Value Converter open as temporary tool rows beneath the path field. The output pane appears below the editor only when needed.

03Files, tabs, and editing

  • Open up to eight ANCL, Python, C#, JSON, XML, HTML, SQL, Markdown, INI, PowerShell, log, text, or other plain-text documents.
  • Each tab preserves its own text, modified state, language override, caret, and scroll position.
  • Use Ctrl+Tab and Ctrl+Shift+Tab to move through tabs.
  • Close any tab directly with its x button, or close the active tab with File > Close or Ctrl+W. ANCL Pad asks before discarding unsaved changes.
  • Open file paths, order, and the active tab are restored on the next launch. Unsaved text is protected by recovery snapshots.
  • The File menu keeps the three most recently opened files for quick access.
  • Find, Replace, Go To Line, build actions, and the value converter operate on the active tab.
  • Matching (), [], and {} pairs are highlighted when the caret touches either bracket.
  • The editor accepts documents up to 1 MiB each.

Encoding and line endings

ANCL Pad detects each file when it opens and displays the active format in the bottom status panel. Format choices belong to each tab.

Encoding

View > Encoding supports ANSI, UTF-8, UTF-8 with BOM, and UTF-16 LE. Unicode text is held internally as UTF-8 so it survives tab switches and format conversion.

Line endings

View > Line Endings supports Windows CRLF, Unix LF, and classic Mac CR. Mixed files use the most common newline style as their detected setting.

  • Changing either setting marks the active document Modified because its saved bytes will change.
  • Save or Save As writes the selected encoding and normalizes every newline to the selected style.
  • New documents default to UTF-8 without a BOM and Windows CRLF.
  • Use UTF-8 for ANCL source unless a specific external system requires another format.

Crash recovery

While any tab is Modified, ANCL Pad writes a portable recovery snapshot every 15 seconds without changing the original source files.

  • A compact manifest and one temporary text snapshot per open tab are stored beside ancl_pad.exe.
  • After a crash, forced termination, or power interruption, the next launch offers Restore or Discard.
  • Restore recreates the open tabs and preserves which documents were Modified.
  • Discard removes the recovery data and continues with the normal saved session.
  • Recovery files are removed automatically after all documents are saved or ANCL Pad closes normally.
Recovery is a safety net, not a replacement for Save. Up to the most recent 15 seconds of typing may be absent after an interruption.

Find in Files

Open Edit > Find in Files or press Ctrl+Shift+F. Enter case-insensitive search text and choose or type the folder scope.

  • Search descends recursively through common source, configuration, markup, and text files.
  • .git, node_modules, .venv, and __pycache__ folders are skipped.
  • Results appear in the bottom output pane as path, line number, and matching-line preview.
  • Click a result to open or activate its file and jump directly to the matching line.
  • Each search is capped at 500 matching lines and 5,000 scanned files.

Line bookmarks

Bookmarks provide quick navigation between important lines in the active document.

  • Press Ctrl+F2 to toggle a bookmark on the current line.
  • Press F2 or Shift+F2 to visit the next or previous bookmark, wrapping at the document ends.
  • Bookmarked lines carry a compact accent marker in the line-number gutter.
  • Use Edit > Clear Bookmarks to remove all bookmarks from the active document.
  • Each tab owns an independent set of up to 256 bookmarks. Bookmarks are session-local and do not alter or accompany the saved file.

Side-by-side comparison

Choose View > Compare Side by Side and select a second file. The active tab remains editable on the left while the selected comparison file opens read-only on the right.

  • Both panes have independent line numbers, syntax coloring, selection, copying, and scrolling.
  • The comparison header identifies the right-hand file. Use its X or View > Close Comparison to return to the full-width editor.
  • Changing tabs updates only the editable left pane, allowing several source files to be inspected against one reference.
  • Compile, Run, Fix, Find, Replace, Save, and bookmarks continue to target the active left tab only.

05ANCL Compile and Run

Build commands are enabled only when the current path ends in .ancl.

1
Save the source inside the portable bundle or another writable folder.
2
Compile calls compiler\anclc.exe and writes the executable plus assembly listing into programs\.
3
Run compiles first, launches the produced executable, and captures output plus exit code.
4
Click an output diagnostic containing line N to jump directly to that source line.

06Mechanical Fix

Build > Fix asks the ANCL compiler to identify deterministic mechanical repairs. You review the number of proposed fixes before writing.

  • The compiler report remains visible in the output pane.
  • Accepted changes preserve the original source as .bak.
  • The repaired file is reloaded and recolored automatically.
  • If no safe fixes exist, the source is left unchanged.
Fix is a compiler-guided repair path, not a general AI rewrite. Its narrowness is part of its safety.

07Starters and import helpers

File > New From Starter loads ready-to-edit ANCL templates for Modbus TCP, MQTT, SQLite, BACnet, DNP3, EtherNet/IP, FINS, IEC 60870-5-104, OPC UA, and S7.

Edit > Insert Import adds common bundle-relative imports at the caret:

import "core_lib/cstring.ancl";
import "core_lib/gui_v2.ancl";
import "core_lib/process_capture.ancl";

Programs saved in the bundle root can compile those paths without installation or environment variables.

09Portable bundle

ancl_pad\
  bin\ancl_pad.exe
  bin\guide.html
  bin\ancl_pad_session.txt
  bin\ancl_pad_recovery*  temporary while unsaved work exists
  compiler\anclc.exe
  core_lib\
  programs\
  sample.ancl
  README.md

Share the complete folder. The Pad executable locates the compiler, libraries, starters, output directory, guide, and sample relative to its own installation. ancl_pad_session.txt is created automatically beside the executable and stores reopenable file paths only. Recovery files appear temporarily while unsaved work exists.

The bundled core_lib is synchronized from the repository root so Pad projects receive the same current libraries as the main ANCL workspace.

11Current limits

  • Compile, Run, Fix, starters, and import helpers target ANCL only.
  • Other language modes do not invoke external runtimes, interpreters, or compilers.
  • The editor is intentionally plain-text based and supports up to eight open tabs.
  • Syntax coloring and bracket matching are lexical, not a full language parser or language server.
  • Bookmarks remain in memory for the current session and are not stored in source files.
  • The value converter currently handles unsigned integer representations.

12Troubleshooting

SymptomResolution
Compile menu disabledSave the active file with an .ancl extension.
Compiler rejects source textSelect View > Encoding > UTF-8 and save the ANCL document again.
Wrong newlines in another toolSelect the required style under View > Line Endings, then save.
Compiler missingPlace anclc.exe at compiler\anclc.exe inside the bundle.
Import cannot be resolvedSave the program in the bundle root or keep a matching core_lib beside the project.
