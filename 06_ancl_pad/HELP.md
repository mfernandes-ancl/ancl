# ANCL Pad — Help

**ANCL Pad** is a native, zero-dependency code editor for ANCL — a lightweight IDE with syntax
highlighting, an **integrated ANCL compiler** (build + run in place), and a rich standard library.
Written in ANCL; source included.

## Launch

```
bin\ancl_pad.exe
```

Press **F1** (or open `bin\guide.html`) for the full built-in guide.

## What's included

- `bin\ancl_pad.exe` — the editor · `bin\guide.html` — the manual
- `compiler\anclc.exe` — the bundled ANCL compiler (build/run straight from the editor)
- `core_lib\` — the standard library
- `src\ancl_pad.ancl` — the editor's own ANCL source

Everything runs out of the box, offline, zero-dependency.
