Quick-Start Field Guide for Supported Substation & Automation Protocols

Modbus/TCP Port 502

  • Coils (0x): Read/Write single bits. Code: 01 (Read), 05 (Write).
  • Discrete Inputs (1x): Read-only bits. Code: 02.
  • Input Registers (3x): Read-only 16-bit. Code: 04.
  • Holding Registers (4x): Read/Write 16-bit. Code: 03 (Read), 06/16 (Write).

Address Syntax:

00001 (Coil 1), 40002 (Holding Register 2)

Omron FINS Port 9600

  • DM (Data Memory): Hex code 0x82. Primary memory area.
  • HR (Holding Area): Hex code 0xB2. Retentive memory.
  • CIO (Core I/O): Hex code 0xB0. Direct physical I/O mapping.
  • AR / EM Areas: Hex codes 0xB3 / 0x90 (EM Bank 0).

Address Format:

DM100 (Offset 100 in DM), HR20 (Offset 20 in HR)

Siemens S7comm Port 102 / 10200

  • DB (Data Block): User-defined memory blocks.
  • M (Markers): Internal relays/flags.
  • I (Inputs) / Q (Outputs): Physical I/O states.
  • Sizes: Bit (X), Byte (B), Word (W), Double-Word (D).

Address Format:

DB1.DBW2 (Word at DB1 offset 2), MW4 (Word at M offset 4)

IEC 104 Port 2404

  • CA (Common Address): Sector/Station Address (usually 1).
  • IOA (Info Object Address): Specific point index.
  • Commands:
    • Type 45: Single Command (SC)
    • Type 46: Double Command (DC)

Connection Handshake:

Sends STARTDT act. Waits for STARTDT con before ASDU transmission.

IEC 61850 MMS Port 102

  • Object Reference: Structured hierarchy.
  • Syntax: Device/Node.Data.Attribute
  • FC (Functional Constraint): Grouping filter (ST=Status, MX=Measurands, CO=Control, SP=Setpoints).

Example Point:

WTG_Status/MMXU1.TotW.mag.f[MX] (Total Watts float value)

IEC 61400-25 (WIND) Port 10104

  • Object Hierarchy: Tailored wind turbine model (e.g. Wnac1, WROT1, Wmet1).
  • Syntax: LogicalDevice/Node.Data.Attribute
  • FC (Functional Constraint): Filter groups (MX=Measurements, ST=Status, CO=Controls).

Example Point:

WTG1Sim/Wnac1.TurSt.stVal[ST] (Turbine State status value)

Allen-Bradley Port 44818

  • Symbolic Tags: Tags are referenced directly by name.
  • ANSI Segment: Encodes tag names into binary segments.
  • Data Types:
    • BOOL (1-bit), INT (16-bit), DINT (32-bit), REAL (32-bit Float)

Example Point:

WTG_Running (BOOL), WTG_WindSpeed (REAL)

DNP3 Port 20000

  • Binary Inputs / Outputs: Group 1 / 10 (Variation 2 for status/value).
  • Analog Inputs / Outputs: Group 30 / 40 (Variation 1 for 32-bit signed with flags).
  • Counters: Group 20 (Variation 1 for 32-bit with flags).
  • Commands:
    • Group 12 (CROB): Binary control (Index/Control).
    • Group 41: Analog Setpoint command (Index/Setpoint).

Address Syntax:

Grp 41 Var 2 Index 0 Ctrl 999 (Analog setpoint 999 to AO 0)

BACnet/IP Port 47808

  • Analog Input (AI) / Output (AO): Read/Write float values. Type 0 (AI), Type 1 (AO).
  • Analog Value (AV): Read/Write float values. Type 2.
  • Binary Input (BI) / Output (BO) / Value (BV): Read/Write boolean states (0/1). Type 3 (BI), Type 4 (BO), Type 5 (BV).
  • Who-Is Discovery: Unconfirmed service to discover active BACnet devices on the network.

Address Syntax:

AI:0 (Analog Input 0), AV:4 (Analog Value 4), BV:5 (Binary Value 5)

ICCP (TASE.2) Port 10103

  • MMS Association: Standard connection for TASE.2 client/server association.
  • Data Point Mapping: Standardized mapping of telemetry data.
  • Control Operations: Direct control operations on remote points.

Address Format:

/Device/Data.Attribute (MMS hierarchy reference)
