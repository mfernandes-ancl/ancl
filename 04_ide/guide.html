01What is Aether Studio?

Aether Studio is a complete development environment for ANCL — a from-scratch systems language whose compiler emits native Windows PE32+ executables directly (hand-encoded x86-64, its own PE writer, no C runtime, VM, assembler, or linker). Remarkably, the IDE itself is written in ANCL and compiles its own source.

■

All in one

A syntax-highlighting editor, a file tree, a one-key compiler, a program runner, and an AI agent — a single ~390 KB native binary.

▲

AI-native

Chat with a coding agent that can read, compile, and edit your files — powered by a local model, a cloud API, or an offline ANCL brain.

02Quick start (60 seconds)

1
Open a file. Your projects live in Documents\Aether Projects. Click hello.ancl in the tree on the left to open it, or use Ctrl+O.
2
Edit it. Type in the editor. Code is colored as you type; the gutter shows line numbers and the status bar shows Ln, Col.
3
Compile. Press Ctrl+B (or the Compile button). The compiler's output streams into the pane at the bottom. Errors are clickable — the editor jumps to the failing line.
4
Run. Press F5 to build and run; the program's output and exit code appear in the output pane.
5
Stuck on an error? Press Fix for a one-click mechanical repair, or ask the AI assistant on the right.
Tip — New (or Ctrl+? from the File menu) scaffolds a ready-to-compile console app from a template, so you always start from working code.

03The interface

The window is split into five working areas:

  • Activity rail (far left) — quick icons: open folder, search, AI, settings.
  • File tree — your workspace folder. Click a file to open it in a tab. Double-click a name to rename it. Binary files (.exe, .ico, …) are protected from being opened as garbage text.
  • Editor (center) — a syntax-colored code editor with a line-number gutter and multi-file tabs (up to 8 open documents).
  • Output pane (bottom) — compiler messages, program output, and smart-compiler reports.
  • AI chat rail (right) — the Aether Agent: a transcript, an input box, Send/Stop, and an image-attach button for vision.

A menu bar (File · Edit · Build · Help) and a toolbar (Open · Save · Compile · Run · Settings · Fix) sit across the top; a status bar runs along the bottom.

05The smart compiler SELF-CORRECTING

Aether's compiler doesn't just reject mistakes — it can heal them. Two tiers are built right into the IDE:

Fix — mechanical auto-fix (offline, instant)

Press the Fix button (toolbar), Build › Auto-Fix, or just type fix in the chat box. The compiler runs a dry run first and shows exactly what it would change in the output pane; you confirm, and it applies the fixes and reloads the healed source. Your original is always preserved as a .bak file. It's fully deterministic and needs no AI.

It heals the most common slips automatically:

You wrote (C habits):

// add two numbers
func add(a: i32, b: i32) -> i32 {
    return a + b   <- missing ;
}

Fix heals it to:

# add two numbers
func add(a: i32, b: i32) -> i32 {
    return a + b;
}

Handles: // → # comments; missing ; ) ] } -> =>; and C-isms like bool/true/false/float/double → their ANCL equivalents.

AI Repair — when the fix isn't mechanical

For logic and structural errors, use Build › AI Repair… (or type repair in chat). The IDE compiles your file, captures the real compiler errors, and hands them — with your source — to the AI agent. The agent reads the file, fixes only what's needed, and writes a corrected version back. You review the proposed change before it's applied (type apply or reject in the chat).

The compiler is the judge. A wrong AI patch simply fails to compile and the loop tries again — a broken program can never be silently shipped.

06Editor features

Find & Replace

Press Ctrl+F. The bar appears in the toolbar row. Type and press Enter to find the next match (case-insensitive, wraps around). Close it with the ✕ button or Esc.

Command palette

Press Ctrl+Shift+P for a searchable list of every command — New, Compile, Run, Auto-Fix, AI Repair, Settings, User Guide, and more.

Tabs

Open up to 8 files at once. Unsaved tabs show a *. Switch tabs from the strip above the editor.

Syntax highlighting

Keywords, types, builtins, strings, and comments are colored live as you type, driven by a native ANCL tokenizer.

07The AI assistant

The right-hand rail is an agentic assistant, not just a chat box. It can use tools to act on your project:

  • read_file — read a file in your workspace.
  • list_dir — list a folder.
  • compile_file — invoke the native compiler and read back the result.
  • write_file / create_file — propose edits to your code.

When the agent edits the file you have open, the change is shown to you first — type apply to accept it into the editor or reject to discard it. Press Stop to cancel mid-generation.

AI-native completion & intent NEW

Beyond the chat, Aether Studio has a tiny, local op-brain that predicts code structure (the compiler's AST) rather than text — so it is instant, fully offline, and can only ever suggest valid ANCL constructs.

ShortcutWhat it does
Ctrl+SpaceAI autocomplete — the op-brain predicts the next code structure; suggestions appear in the Output pane.
Ctrl+Shift+IPlan from Intent — reads your # @INTENT goal, the router classifies it (ancl / protocol / both / chat), and the Aether Agent is pre-loaded with a prompt to implement it. Then just press Send.

State your goal at the top of a file in an @INTENT block (New Project seeds one for you):

# @INTENT
# goal: build a modbus tcp logger with a gui window
# skills:

This is the intent-driven pipeline: you state the goal → the router picks the skills & a starter template → the Agent (or templates) fill it in → the compiler verifies every step. AI output is checked, not trusted.

Tiered & local-first — the op-brain routes & completes for free and offline; it escalates to your chosen LLM only for the heavy generation.

Captured-frame tools NEW

Sniffed some industrial traffic and want to know what it is — or whether it's safe? Paste a captured frame's raw hex bytes into the editor, then:

ShortcutWhat it does
Ctrl+Shift+FIdentify protocol — the learned frame brain names the industrial protocol and loads a compile-ready starter client to talk to it.
Ctrl+Shift+AAnomaly-check — the edge-IDS brain reports normal or ANOMALY with the reason (out-of-profile access, malformed frame, or out-of-range value) plus the decoded op / address / value. Modbus, FINS & IEC-104 today.

Both run fully offline against tiny pure-ANCL models — no cloud, no dependencies, CRT-free like the rest of Aether Studio.

09ANCL in 5 minutes

Enough to read and write the examples. A program is a set of funcs; execution starts at main, whose return value is the process exit code.

Hello, world

@DATA
banner: str = "Hello from a native ANCL program!\n";

@CODE
func main() -> i32 {
    syscall 1, banner;   # write the string to stdout
    return 0;            # exit code 0
}

Functions, types, and an exit code

func square(n: i64) -> i64 {
    return n * n;
}

func main() -> i64 {
    return square(7);    # the process exits with code 49
}
  • Comments start with #.
  • Integer types: i32, i64; floats: f64; strings live in @DATA as str.
  • Sections: @DATA for constants/strings, @CODE for functions.
  • Statements end in ; — and if you forget, the Fix button has your back.
Learn by example — use New for a working console app, or open the bundled templates\ and src\ files (the IDE's own source) to see real, substantial ANCL.

11Tips & FAQ

The AI reply is empty / never comes.

Check Settings: for Ollama, make sure the server is running and a model is selected (use Refresh models). Small local models can be slow on the first call while they load — give it a few seconds. For cloud backends, confirm the relevant API-key environment variable is set.

My build fails with a parse error.

Click the error in the output pane to jump to the line, then press Fix for mechanical slips (missing ;, // comments) or AI Repair for anything deeper.

Where are my files?

Documents\Aether Projects by default. Use Open Folder (File menu or the rail's folder icon) to work anywhere else. The IDE's own install folder is kept separate so you can't break it.

Is anything sent to the cloud?

Only if you choose a cloud backend. Ollama, the Local Brain and the Aether Engine are fully offline.
