01Quick start

1
Run aether_lens.exe. Keep aether_engine.exe beside it. Lens starts and stops only the local Engine process it owns.
2
Review the first-run recommendation. On a clean launch Lens reads total system RAM locally and suggests a conservative Engine model. RAM is not VRAM, and accepting only selects the model; nothing downloads automatically.
3
Pull explicitly. Keep the recommendation or choose another compatible Library model, then press Pull. Lens reports completion percentage and downloaded/total size while Engine streams and SHA-256 verifies it.
4
Start chatting. Type in the lower composer and press Enter or the purple arrow.
Aether Engine, Full GPU, Direct answer, unrestricted Unicode, and a standard 128-token reply are the friendly defaults. If Full GPU cannot start, try Conservative GPU and then CPU reference. Lens remembers later changes.

03Models and downloads

Library→Select exact tag→Pull→Download %→SHA-256 verified→Inspect→Use
  • Library is a curated list of exact public tags that match architectures Aether Engine supports.
  • Pull downloads model blobs into the portable models\ store and verifies their manifest digest.
  • The status line shows percentage plus downloaded and total sizes during a live transfer.
  • Refresh lists installed models; clicking a row inspects it without switching.
  • Use checks the native GGUF report and switches only when it says Forward status: supported.
  • An installed or shared-store model can remain inspectable while being unrunnable by this Engine. Lens blocks that switch and preserves the current working model.
  • A compatible typed tag can still be used when it is not in the curated menu.
Installed does not always mean runnable. The Engine can discover models from shared Aether/Ollama stores, including architectures meant for Ollama or a future Engine. If inspection reports unsupported or incomplete metadata or metadata-only / not yet runnable, Lens refuses Use and local Send with a clear warning.
Exact names matter. A guessed tag such as gemma4:7b can return registry HTTP 404. Prefer a Library entry such as gemma3:4b. Models are deliberately excluded from the initial portable ZIP because they range from hundreds of megabytes to many gigabytes.

Model Arena

Press the cyan ARENA button to open the full workspace directly. Choose installed contenders from the Studio-style dark Model A and Model B dropdowns. The aligned, outlined prompt field displays a muted Write your Arena prompt here… cue while empty; that cue is never sent. Type the dedicated Arena prompt and press Run Showdown. Both contenders receive the identical isolated prompt and Specialist route sequentially; chat history, knowledge, and attachments are excluded for fairness. Pair and prompt controls lock while running.

The answer panes shuffle blind left/right sides, show Pulse measurements, and accept one Left, Right, or Tie vote before revealing the side mapping. Options controls blind mode and the readable local TSV history, which stores model names, vote, prompt SHA-256, and measurements—not prompts or full answers.

04Aether Engine automatic mode

Aether Engine is the clean-install default and uses http://127.0.0.1:11435. Lens probes that endpoint before doing anything else.

If no server is running

Lens launches the adjacent executable with the selected model, port, and checked hardware flags, waits for readiness, and keeps the process handle.

If a server already exists

Lens reuses it without claiming ownership. Remote or independently started servers are never terminated by Lens.

aether_engine.exe serve <model> 11435 gpu

The equivalent command is shown for transparency; normal users do not need to run it manually.

Portable discovery: Engine first checks the bundle's models\, then a shared %USERPROFILE%\.aether\models store, and can read compatible models already present in Ollama's store without downloading a duplicate.

04VNative Engine vision

gemma4:e4b can understand image pixels directly through Aether Engine. No Ollama installation, vision sidecar, separate projector, cloud call, or new Lens dependency is required.

Attach / paste PNG→gemma4:e4b reads pixels→grounded reply

Direct vision

Select gemma4:e4b, attach one PNG, and send normally. Lens puts the PNG's raw bytes in the standard images[] field and sends the question in the same /api/chat request.

Helper vision

With a text-only Engine model, Auto or First vision model runs an installed gemma4:e4b against the user's exact question, restores the chosen chat model, and labels the result as authoritative pixel-grounded evidence. Lens switches only a local Engine process it owns.

  • The transcript shows a bounded helper-evidence excerpt before the final answer, making it clear whether any mismatch came from vision or the chat model.
  • The current Engine contract accepts one PNG per message. JPEG, GIF, and WebP remain previewable but are not sent to native Engine vision.
  • Lens checks the complete serialized vision request against the Engine's current 256 KiB HTTP envelope; an oversized image/context combination remains preview-only and is marked not sent.
  • Moondream is an Ollama-only helper preference. Off disables helper routing, but direct gemma4:e4b vision still works.
  • The vision tower currently runs CPU float64 and may take about one minute before generation begins. Pulse reports reading image locally so the request does not look frozen.
  • The transcript distinguishes an image sent to native vision from one that was not sent.
Local means local: the attached PNG travels only to the configured Engine endpoint. Privacy Proof shows whether that endpoint is loopback or network/cloud and whether direct/helper vision is available.

07Rich Answers and Document Canvas

Assistant Markdown is presented non-destructively: headings, bold text, inline code, fenced code blocks, lists, tables, quotations, and compact label-only links. The underlying transcript remains plain portable text.

  • Choose Markdown, HTML, or SVG under Add > Document Canvas, then write the request normally.
  • Lens treats the entire visible answer as the selected document type; the model does not need to produce an outer fence.
  • The separate Canvas edits, copies, and saves only when you explicitly choose Save or Save As. Markdown previews in the window.
  • HTML/SVG Safe Preview validates the current edited source and opens only accepted content in the permissionless browser sandbox.
  • Right-click an existing answer and choose Open last answer in Document Canvas to open it as Markdown.
  • Copy or save the last complete fenced code block with a language-aware extension.
  • Preview the last complete html, htm, or svg fenced block as a read-only visual artifact.
  • Show or hide backend <think> reasoning; the choice is remembered.
  • HTTP and HTTPS links always ask before opening the default browser.
Canvas is a local draft, not automatic storage. Closing an edited unsaved Canvas asks first, and Lens never chooses a destination folder for you.

Sandboxed artifacts

Assistant markup is untrusted. Lens caps it at 256 KiB and fails closed on scripts, event handlers, forms, frames, external resources, navigation, unsafe CSS, active SVG features, and local/network schemes. The inert standard SVG namespace is allowed. Accepted markup receives a restrictive Content Security Policy and opens inside a permissionless sandboxed iframe. Generated files live under chats\artifacts\.

Unsafe markup is not repaired or silently weakened: Lens blocks Safe Preview while Copy and Save remain available. The viewer uses the Windows default browser and adds no WebView, Node.js, Python, Ollama, or other bundled runtime.

Code and document source in Lens can be read, copied, saved, exported, and safely previewed when inert, but never compiled or run. Project editing and compiler workflows belong to Aether Studio and ANCL Pad.

08Lens Pulse

Pulse normalizes performance information from Aether Engine and Ollama into one view.

While generating

  • Preparing, waiting, streaming, stopped, or failed state
  • Time to first token and live elapsed time
  • Live token and speed estimates

After completion

  • Exact prompt, reply, and context tokens
  • Prompt, generation, load, and total timing
  • Tokens/second, stop reason, and five-reply speed history

The compact status summary remains when the detailed panel is collapsed. Pulse visibility survives restart.

10Local document and folder knowledge

Local knowledge is the persistent counterpart to a one-message attachment. Lens copies an explicitly selected text file or folder corpus into the portable knowledge\ store, then uses deterministic lexical retrieval for later questions.

Add→Knowledge: Index file/folder→Ask a question→[K1]–[K3] passages→Open cited passage

What Lens indexes

  • TXT, Markdown, ANCL, CSV, JSON, XML, HTML, LOG, INI, CFG, and YAML text
  • At most 256 KiB per file and 4 MiB total
  • Up to 96 files and folder depth 6
  • Generated and dependency folders are skipped

What reaches the model

  • Only the best three bounded lexical passages
  • Original source path and exact line range
  • An instruction to cite claims as [K1], [K2], or [K3]
  • No embedding service, vector database, or network request

After each knowledge-assisted prompt, the transcript records exactly which passages were sent. Click Open cited passage to reopen Lens's archived excerpt even if the original folder later moves.

Add menu actionPurpose
Index one file / Index folderReplace the current corpus with a fresh, explicit snapshot. Original files remain untouched.
Use indexed sourcesChecked when retrieval is active. Disable it without deleting stored data.
Show indexList retrieval state, storage path, limits, original source paths, and copied byte counts.
Open storage folderInspect the readable manifest, copied documents, and generated citation excerpts directly.
Clear indexDelete only Lens's copied corpus and excerpts after confirmation.
Truthful retrieval: if no indexed passage matches the question, Lens says that no knowledge was sent. It does not inject the entire folder or pretend semantic certainty.
The V1 index is a snapshot. Re-index after source documents change. Knowledge is read-only assistance; indexing a source tree never authorizes Lens to edit, build, or run it.

Right-click anywhere in the transcript to work with the latest exchange. These actions operate on the canonical plain-text conversation, so they behave the same after Save and Load.

Safe branching

First Save the current chat. Then type a new Chat name and choose Load > Branch current to Chat name. Lens writes the current transcript to a new .lens file, switches to it, and leaves the original file byte-for-byte untouched. It refuses the same name or an existing destination. Relative chats\assets\ links remain valid in both branches.

12Saved chats

  • Save writes chats\<Chat name>.lens.
  • Save As chooses another path and updates Chat name.
  • Load lists recent chats and provides Browse, Open chats folder, Duplicate, safe Branch, Rename, and Delete.
  • Export writes a readable Markdown copy.
  • Copy copies the complete plain transcript.
  • New clears the current conversation after the normal busy-state checks.
Rich formatting is a presentation layer. Save, Load, branch, Copy, and Export continue to use stable plain text, keeping conversations readable without Lens.

♪Voice — still in development

Voice transcription is temporarily hidden from the Lens interface. The tested legacy Windows SAPI recognizer is fully local but was not reliable enough across real speech and accents to present as a finished feature.

Current release status: Voice is retained for development work while Lens evaluates a more reliable optional local transcription engine. It is not a supported feature in this release.

No recorded audio has been sent to a model or cloud provider by the prior local implementation.

Privacy Proof

Press Proof and choose Show Privacy Proof for a native, read-only report generated without a model or network request. It classifies the active endpoint as local loopback or network/cloud, computes the adjacent Aether Engine executable SHA-256 locally, shows the selected model digest when inspectable, reveals queued attachments and knowledge context state, and lists every portable storage path.

The same menu opens the app, chats, knowledge, Arena, and model folders. Confirmed clear actions remove only the current in-memory conversation, copied knowledge, generated artifact previews, or Arena preferences. Saved .lens files and chats\\assets attachment archives are never bulk-deleted silently.

Auditable network state: choosing a cloud/remote endpoint is explicit, and the proof labels it NETWORK / CLOUD before a message is sent. API keys remain environment-only and are never displayed.

15Product boundary

Aether Lens is the compact general-purpose AI desktop: chat, models, documents, media, voice, comparison, performance transparency, and privacy UX.

Lens owns

Private conversation, model management, knowledge/media assistance, safe answer artifacts, Pulse, and backend choice.

Studio and Pad own

Project editing, compilers, build/run/debug loops, autonomous source changes, and compile-fix workflows.

A future one-way “Open in Studio/Pad” handoff may be useful, but Lens will not duplicate those products.

16Troubleshooting

SymptomWhat to check
Help shows compact text insteadKeep guide.html beside the portable executable, or at the Lens project root when running bin\aether_lens.exe.
Pull returns HTTP 404Use an exact Library tag. The requested model/tag probably does not exist in the public registry.
Download appears slowLarge models are several GB. Watch percentage and transferred/total sizes; SHA-256 verification is part of the same secure flow.

Local tools

Typed Document Canvas: Add offers Markdown, HTML, SVG, and CSV. HTML/SVG use Safe Preview; CSV validates quoted fields and consistent column counts. Lens removes one complete matching outer fence when a small model adds it.

Offline Calculator

Choose Add > Local Tools > Calculator for deterministic arithmetic without asking a model or contacting the network. It supports decimal numbers, parentheses, unary signs, and +, -, *, / with normal precedence.

  • Evaluate shows the local result or a clear syntax/divide-by-zero message.
  • Copy result writes only the valid result to the clipboard.
  • Insert in composer places the valid result at the current cursor and never sends automatically.

Integer base converter

Enter a non-negative 63-bit integer as decimal, 0x hexadecimal, or 0b binary. Optional underscores may group digits. Convert synchronizes Dec, Hex, and Bin; Copy Conversions or Insert Conversions handles the complete labelled set without sending.

Permissioned Web Reader

Choose Add > Local Tools > Web Reader, paste one explicit HTTP/HTTPS URL, and approve the dialog naming the exact host and URL. Lens downloads at most 128 KiB with 15-second network-phase timeouts, blocks automatic redirects, removes markup plus script/style content, and displays inert readable text only.

  • Credentials, fragments, file URLs, malformed ports, and unsafe URL characters are rejected before connecting.
  • The result records the exact source URL, local retrieval time, HTTP status, and readable byte count.
  • Copy text and Insert excerpt retain the source URL. Insert never sends automatically.
  • Stop or closing the reader aborts the active request; partial stopped content is not accepted.

Embedded Search Google

Choose Add > Local Tools > Search Google, enter a query, and review the exact URL before approval. The real Google page appears beneath the search controls in an embedded WebView2 browser.

  • This pane is active web content: Google scripts, cookies, links, and media run inside an isolated Lens browser profile.
  • Native ANCL code locates the Windows-installed Evergreen runtime directly. Lens bundles no WebView2 loader DLL or browser runtime.
  • Lens does not scrape the page or send the query to a model. If embedding is unavailable, the same approved URL opens in the default browser.
  • Proof discloses the webview2-profile folder and can clear its cookies, cache, and site storage after the Search window is closed.
  • To create inert attributed model context, paste a chosen page URL into Web Reader and approve its bounded fetch.
Permission boundary: Calculator and converter are offline. Embedded Search Google is clearly active browser content. Web Reader is the bounded inert-text path and asks before every download.
