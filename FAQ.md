# ANCL — Frequently Asked Questions

**Is this really one project?**
No. It started as one project. Things escalated from there.

**Did one person really build all this?**
Unfortunately, yes. With the help of AI.

**What does ANCL stand for?**
"Natural Coding Language." The N, C, and L, at least. The A is still under discussion — Aether, AI,
or just "a," depending on the day and who's asking. We'll get back to you.

**Why does this repository contain a compiler, an IDE, an AI assistant, a spreadsheet, an OPC
Explorer, protocol testers, protocol simulators, games, and a 3D engine?**
Dependency fatigue.

**Why did you create ANCL?**
One day I needed a simple tool. The tool needed more dependencies than the problem I was trying to
solve. I may have overreacted.

**Was ANCL supposed to become an ecosystem?**
Absolutely not. The original objective was significantly smaller.

**Is that really a native executable?**
Yes.

**Where is the installer?**
There isn't one.

**Where is the runtime?**
There isn't one either.

**What framework does it use?**
ANCL.

**Why is the executable so small?**
Because it contains software instead of dependencies.

**Does it support OPC UA?** Yes.
**OPC DA?** Yes.
**OPC XML-DA?** Yes.
**Modbus?** Yes.
**S7?** Yes.
**DNP3?** Yes.
**BACnet?** Yes.
**IEC-104?** Yes.

**Why?**
I work with C&I and SCADA tools.

**What is ANCL trying to become?**
At this point, we are all waiting to find out.
